# docs/ — primary source store

PDFs and HTML snapshots supporting the research artifact. Prefer citing via `sources.md` IDs (`R01`, `P01`, …).

## Rules
- Never invent clause numbers; open the local file.
- Paywalled/downloaded PDFs are gitignored at `project/.gitignore`.
- **WASA:** no official public specification located (2026-08-27). Do not invent a WASA PDF entry. See `../logs/wasa-absence-finding.md`.

## Layout
- `papers/` — literature
- `regulatory/` — DPDP, ABDM, NRCeS
- `standards/` — OWASP, CWE, FHIR landings
